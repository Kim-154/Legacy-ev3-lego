# Legacy 🤖

Built in 2024 📅

LEGO Mindstorms EV3 robot simple experimented program.

## What it does

Legacy is a sumo robot. Its program works in two steps:

1. **Search:** Legacy spins in place until its proximity sensor detects an object (the opponent).
2. **Attack:** Once it locks on, it drives straight toward the target and pushes it until it falls outside the ring.

## Hardware/Set up
- Motors: LEGO EV3 Body 
- Proximity Sensors: Mounted at the lower front
- Built from the LEGO instruction booklet (with modifications)


## How to run
1. Open `LEGACY_CODE_FCT.lmsp` in the LEGO software.
2. Connect to the EV3 brick and download the program.
3. Run it.
